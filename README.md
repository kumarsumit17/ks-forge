# KS Forge

A fast, private terminal for macOS and Windows, part of [KS-Suite](https://github.com/kumasumit/KS-Suite). Free: no ads, no analytics, no account.

- **Tabs and split panes**: split right or down to any depth, drag dividers, move between panes with the keyboard, zoom a pane, rename tabs and give them an icon and colour.
- **Profiles**: zsh, bash and fish on macOS; PowerShell, Windows PowerShell, Command Prompt, Git Bash and WSL on Windows are found by themselves. Each profile has its own folder, variables, theme and icon.
- **Themes**: ten of our own colour schemes, light and dark, following the system if you like; import and export themes as JSON; an accent colour.
- **Fonts**: any installed monospace font, size, line height, weight, and ligatures.
- **Keyboard**: shortcuts that feel native on each system, every one changeable; a command palette for everything.
- **Find** in the scrollback (case, whole word, regular expression), clickable links, a warning before pasting several lines.
- **Shell integration** for zsh, bash, fish and PowerShell: new tabs open in the current folder, jump between commands, failed commands are marked. Your own startup files are never edited.
- **Settings** on a settings screen and in one `settings.json` that applies as soon as you save it.
- English and Hindi.

## Download

From the [latest release](https://github.com/kumasumit/ks-forge/releases/latest): `…-macos-arm64.dmg` for Macs with Apple silicon, `…-windows-x64-setup.exe` for Windows. Neither is signed by Apple or Microsoft yet; the release notes say how to open them the first time.
